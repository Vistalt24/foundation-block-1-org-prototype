# Foundation Block 1 — интерактивный прототип оргструктуры

Живой кликабельный прототип организационной структуры (Block 1) для
компании 20–100 человек. Один файл (`index.html`), без сборки и без
бэкенда — всё состояние живёт в памяти вкладки браузера. Интерфейс
полностью на русском.

## Открыть

Публичная ссылка (без установки, без авторизации):
**https://vistalt24.github.io/foundation-block-1-org-prototype/**

Локально — просто открыть `index.html` двойным кликом, либо поднять
любой статический сервер из этой папки, например:

```
python -m http.server 8000
```

и открыть `http://127.0.0.1:8000/`.

## Что внутри

- Компактная синтетическая компания **«Стройсервис»** (10 сотрудников,
  3 постоянных отдела, 1 постоянная бригада внутри производства,
  1 временный проект — «Объект Ганновер»).
- Split View: дерево слева, карточка узла справа.
- Карта структуры: визуальная карта блоков с zoom.
- Drag & Drop в дереве: перетаскивание подразделения/бригады/проекта
  в другой узел (с подтверждением и защитой от циклов) и перетаскивание
  сотрудника из карточки в другой узел (с выбором «дополнительная связь»
  / «сделать основным подразделением»).
- Полный набор действий из задания: добавление/переименование/смена
  типа узла, назначение руководителя/И.О., перемещение сотрудника,
  дополнительная (проектная) связь, временное основное назначение,
  перенос ветки, закрытие/архивирование с предварительным просмотром
  последствий (архивировать ветку / перенести дочерние / отмена),
  поиск, «Требуют назначения», предупреждения (нет руководителя,
  слишком глубокая структура).

## Ограничения

- Состояние живёт только в памяти вкладки — обновление страницы
  сбрасывает все изменения обратно к исходным синтетическим данным.
  Это осознанно: прототип для проверки поведения, не для реального
  использования.
- Нет бэкенда, нет сохранения, нет авторизации.
- GitHub Pages может собирать новую версию до пары минут после push —
  если после обновления код видно в репозитории, а на сайте нет,
  подождите немного и обновите страницу.
