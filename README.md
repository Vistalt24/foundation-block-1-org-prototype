# Foundation Block 1 — интерактивный прототип оргструктуры

Живой кликабельный прототип организационной структуры (Block 1) для
компании 20–100 человек. Один файл (`index.html`), без сборки и без
бэкенда — всё состояние живёт в памяти вкладки браузера.

## Открыть

Опубликованная версия (ничего ставить не нужно):
**см. `PROTOTYPE_URL` в отчёте Lead.**

Локально — просто открыть `index.html` двойным кликом, либо поднять
любой статический сервер из этой папки, например:

```
python -m http.server 8000
```

и открыть `http://127.0.0.1:8000/`.

## Что внутри

- Синтетическая компания **Lindenhof Pflegedienste** (~63 сотрудника,
  4 постоянных отдела, 1 филиал, 2 постоянные бригады, 1 временный
  проект с вложенной временной бригадой, Smart Unassigned).
- Split View: дерево слева, карточка узла справа.
- Org Map: визуальная карта блоков с zoom.
- Полный набор действий из задания: добавление/переименование/смена
  типа узла, назначение руководителя/И.О., перемещение сотрудника,
  вторичная (проектная) связь, временный Primary Override, перенос
  ветки (со встроенной защитой от циклов), закрытие/архивирование с
  Impact Preview (Archive subtree / Reparent children / Cancel), поиск,
  предупреждения (нет руководителя, слишком глубокая структура).

## Ограничения (см. также отчёт Lead)

- Состояние живёт только в памяти вкладки — обновление страницы
  сбрасывает все изменения обратно к исходным синтетическим данным.
  Это осознанно: прототип для проверки поведения, не для реального
  использования.
- Нет бэкенда, нет сохранения, нет авторизации.
